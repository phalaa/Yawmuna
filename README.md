# يومنا | Yawmuna Cloud

لوحة عربية للعائلة مع تسجيل دخول مستقل ومزامنة Supabase PostgreSQL.

**ابدأ من [دليل التشغيل العربي](README-AR.md).**

1. نفّذ `database/setup.sql` في مشروع Supabase.
2. أنشئ حساب العائلة من Authentication → Users.
3. أدخل رابط المشروع ومفتاح Publishable في `config.js`.
4. ارفع محتويات المجلد إلى GitHub وفعل Pages من الفرع main والمجلد root.
5. سجّل الدخول بالحساب نفسه على أجهزتك واستورد نسختك القديمة عند الحاجة.

المكتبة اللازمة مرفقة؛ النشر لا يحتاج npm ولا Build.

التطوير والاختبارات: `npm ci` ثم `npm test`.
